## variant
`variant`型からどのように変数を取得するか  
```cpp
std::variant<int, std::string> v = "hoge";
// holds_alternativeを使う
if (std::holds_alternative<std::string>(v)) {
    std::cout << std::get<std::string>(v);
}
// indexも使えるが，マジックナンバーになるので避ける
if (v.index() == 1) {
    std::cout << std::get<std::string>(v);
}
// get_ifをポインターで渡すことで，指定型のポインターを取得できる，指定型を取れない場合にはnullptrが返る
if (std::string* pStr = std::get_if<std::string>(&v)) {
    std::cout << *pStr;
}
// または次項目のvisit
```

## visit
`variant`における`visit`の使い方  
```cpp
// ※
template<class... Ts> struct overloaded : Ts... { using Ts::operator()...; };
template<class... Ts> overloaded(Ts...)->overloaded<Ts...>;
int main()
{
    std::variant<int, std::string> v = "hoge";

    // 全ての型に同じ処理をするとき
    std::visit([](const auto& crArg) {std::cout << crArg; }, v);
    // 全ての型に同じ処理をするとき（戻り値も返せる）
    std::variant<int, std::string> w = std::visit([](const auto& crArg) -> std::variant<int, std::string> {return crArg + crArg; }, v);

    // 各々の型に別の処理をするとき
    std::visit([](const auto& crArg) {
        if constexpr (std::is_same_v<std::decay_t<decltype(crArg)>, int>)
            std::cout << "int with value " << crArg << '\n';
        else if constexpr (std::is_same_v<std::decay_t<decltype(crArg)>, std::string>)
            std::cout << "std::string with value " << std::quoted(crArg) << '\n';
        }, v);

    // 各々の型にオーバーロード処理をするとき
    struct overloaded0
    {
        void operator()(int n) const {std::cout << n << std::endl;}
        void operator()(const std::string& crStr) const {std::cout << std::quoted(crStr) << std::endl;}
        // 新しい型が追加されたときには，ここに定義がないことがエラーになる（なので，バグに気づきやすいかも）
    };
    std::visit(overloaded0{}, v);
    // 各々の型にオーバーロード処理をするとき（上記と同じことをラムダを使って書くと）（※を使う）
    std::visit(overloaded{
        [](int n) { std::cout << n << std::endl; },
        [](const std::string& crStr) { std::cout << std::quoted(crStr) << std::endl; }
        // 新しい型が追加されたときには，ここに定義がないことがエラーになる（なので，バグに気づきやすいかも）
        }, v);
}
```

## constexpr if
`constexpr if`は選択されないブランチのテンプレートの実体化を抑制する．  
`constexpr if`文の中にあるコード（条件文がtrueのときに実行されるコード）は、条件文がtrueの時にしか適格にならない．通常のif文を使うとこれをコンパイルする事はできないが、 `constexpr if`文を用いれば特定の条件を満たした時にだけコードが実体化させることができる．  
if文，else if文には`constexpr`がいるが，else文にはいらない．   
```cpp
template<typename T>
void hoge(T t)
{
    t.fuga(0);
} 
// どこでも実体化はしていない
```
これはコンパイルエラーにならない．∵まだ関数hogeはどこでも実体化されていないから．  
しかし，テンプレートは具体的な型を渡され実体化して、初めてコードが正しいかどうか判定してコンパイルされるわけではなく，宣言の時点でもコンパイルされる部分はある．   
```cpp
template<typename T>
void hoge(T t)
{
    fuga(0);
} 
// どこでも実体化はしていない
```
これはコンパイルエラーになる．∵まだ関数fugaはどこにも宣言されていないから． 
```cpp
template<typename T>
void hoge(T t)
{
    if constexpr (false) {
        g();
    }
}
```
これはコンパイルエラーになる．
```cpp
template<typename T>
void hoge()
{
    if constexpr (std::is_same<T, int>{}) {
        // Tがintのときのみ実行されてほしいが，常に実行されてしまう
        static_assert(false);
    }
}
```
`static_assert(false)`はテンプレート仮引数Tに依存していないため，テンプレートの宣言時に検証され，コンパイルエラーとなる．
さすれば，どうすればいいかというと 
```cpp
template<typename T>
void hoge()
{
    if constexpr (std::is_same<T, int>{}) {
        static_assert(std::is_same<T, int>{});
    }
}
```
とすればいいが，なにか無駄なような気がので，さらに無駄をなくすために 
```cpp
using <typename ...>
constexpr bool false_v = false ;
template <typename T>
void f(T t)
{
    if constexpr (std::is_same<T, int>{}) {
        // テンプレートを使っているので，Tがintのときのみ実行される
        static_assert(false_v<T>);
        // これでもよい
        static_assert([]{return false;}());
    }
}
```

## 可変長テンプレート
```cpp
void write()
{
    // 引数がなくなったときに呼ばれる
}

template <typename T1, typename... T2>
void write(T1 arg, T2... vlist)
{
    std::cout << arg << " ";
    write(vlist...);    // 第一引数を引っ剥がして，再帰する，ただし引数がなくなったときには，引数なしのオーバーロードが呼ばれる
}

template <typename... T>
void writeout(T... argv)
{
    std::time_t now = std::time(nullptr);
    tm local;
    localtime_s(&local, &now);
    std::cout << std::put_time(&local, "%T") << " : ";
    write(argv...);
    std::cout << std::endl;
}

int main()
{
    writeout(42, "fox", 3.14);
}
```

## 時間計測クラス
```cpp
#include <chrono>
#include <thread>

// ナノ秒     std::chrono::nanoseconds  std::chrono::duration</*signed integer type of at least 64 bits*/, std::nano>
// マイクロ秒 std::chrono::microseconds std::chrono::duration</*signed integer type of at least 55 bits*/, std::micro>
// ミリ秒     std::chrono::milliseconds std::chrono::duration</*signed integer type of at least 45 bits*/, std::milli>
// 秒         std::chrono::seconds      std::chrono::duration</*signed integer type of at least 35 bits*/, std::ratio<1>>
// 分         std::chrono::minutes      std::chrono::duration</*signed integer type of at least 29 bits*/, std::ratio<60>>
// 時         std::chrono::hours        std::chrono::duration</*signed integer type of at least 23 bits*/, std::ratio<3600>>
// 日         std::chrono::days         std::chrono::duration</*signed integer type of at least 25 bits*/, std::ratio<86400>>
// 週         std::chrono::weeks        std::chrono::duration</*signed integer type of at least 22 bits*/, std::ratio<604800>>
// 月         std::chrono::months       std::chrono::duration</*signed integer type of at least 20 bits*/, std::ratio<2629746>>
// 年         std::chrono::years        std::chrono::duration</*signed integer type of at least 17 bits*/, std::ratio<31556952>>
template<typename T = std::chrono::milliseconds>
struct Timer
{
protected:
    std::chrono::time_point<std::chrono::high_resolution_clock> m_start;
public:
    Timer() { start(); }
    void start() { m_start = std::chrono::high_resolution_clock::now(); }
    //T::rep elapse0() const { return std::chrono::duration_cast<T>(std::chrono::high_resolution_clock::now() - m_start).count(); }
    template <typename T0 = T::rep>
    T0 elapse() const { return std::chrono::round<std::chrono::duration<T0, T::period>>(std::chrono::high_resolution_clock::now() - m_start).count(); }
    template <typename T0 = T::rep>
    T0 elapsecast() const { return std::chrono::duration<T0, T::period>(std::chrono::high_resolution_clock::now() - m_start).count(); }
};

int main()
{
    using namespace std::literals::chrono_literals;
    Timer timer;
    std::this_thread::sleep_for(std::chrono::milliseconds(1000));
    std::this_thread::sleep_for(1000ms);
    // ^ using namespace std::literals::chrono_literals;が必要，
    // ^ そうすることにより，std::chrono::duration型の変数定義ができる（"ns""us""ms""s""min""h"）
    long long n = timer.elapse();
    unsigned int m = timer.elapse<unsigned int>();
    double mm = timer.elapsecast<double>();
}
```

## thread/async
```cpp
#include <iostream>
#include <vector>
#include <thread>

int main()
{
    const unsigned int threadNum = std::thread::hardware_concurrency();
    static const unsigned int NUM = 10;
    std::vector<std::vector<int>> even(threadNum);
    std::vector<std::thread> threads;
    for (unsigned int cnt = 0; cnt < threadNum; cnt++) {
        // threadは作成した時点から，実行され始める
        // なので，joinを呼んで，その実行が終わるのを待たなければならない
        // また，作成ループ内でjoinをコールしたら，スレッドを作成することの本末転倒になる
        threads.emplace_back(std::thread([cnt, &v = even.at(cnt)]{
            v.resize(NUM);
            for (int i = 0; i < NUM; i++) v.at(i) = 2 * (NUM * cnt + i); }));
    }
    for (std::thread& th : threads) {
        // joinで待つことに関しては，すでに処理が終わっているのには，待ち時間がないのでループで回しても良い
        th.join();
    }
    for (const std::vector<int>& v : even)
        for (const int& i : v)
            std::cout << i << std::endl;
    return 0;
}
```
```cpp
#include <iostream>
#include <numeric>
#include <future>

int main()
{
    const unsigned int taskNum = std::thread::hardware_concurrency();
    static const unsigned int NUM = 10;
    std::vector<std::vector<int>> even;
    std::vector<std::future<std::vector<int>>> tasks;
    for (unsigned int cnt = 0; cnt < taskNum; cnt++) {
        // std::launch::async 非同期的にタスクを実行するために新しいスレッドを起動します
        // std::launch::deferred 最初に結果が要求されたとき(std::future::getが呼ばれたとき)，呼び出し元スレッドでタスクを実行します
        // いずれもおそらく二回目以降は，（何も実行されずに）前に実行したのと同値を返す
        tasks.emplace_back(std::async(std::launch::async, [cnt] {
            std::vector<int> v(NUM);
            std::iota(std::begin(v), std::end(v), cnt * static_cast<int>(NUM));
            return calc(v); }));
    }
    for (std::future<std::vector<int>>& t : tasks)
        even.push_back(t.get());
    for (const std::vector<int>& v : even)
        for (const int& i : v)
            std::cout << i << std::endl;
    return 0;
}
```

## 構造化束縛
`pair`や`tuple`を分解することができる． 
```cpp
std::pair<std::string, double> p0 = std::make_pair<std::string, double>("1", 2.0);
auto [s0, d0] = p0; // copy
auto& [s1, d1] = p0; // ref
const auto& [s2, d2] = p0; // ref
auto [s3, d3] = std::move(p0); // move（moveするので，上記s1,d1,s2,d2は無効になる）
```
```cpp
std::pair<std::string, double> p0 = std::make_pair<std::string, double>("1", 2.0);
std::string s0;
double d0;
std::tie(s0, d0) = p0; // copy
// 変数への参照を持つtupleを作る
std::tuple<std::string&, double&> t = std::tie(s0, d0);
```

## 簡易並列/ベクトル処理
```cpp
std::vector<int> v1(1000, 0), v2;
std::iota(std::begin(v1), std::end(v1), 0);
// 並列化処理，ベクトル化処理可能
std::for_each(std::execution::par, std::begin(v1), std::end(v1), [](int& n) {n += 100; });
std::for_each(std::execution::par_unseq, std::begin(v1), std::end(v1), [](int& n) {n += 100; });
// 並列化処理だと処理が競合するため，mutexまたはatomic操作でデータ競合を回避する
std::mutex m;
std::for_each(std::execution::par, std::begin(v1), std::end(v1), [&v2, &m](int& n) {
    n += 100;   // ほんとはもっと時間のかかる処理
    {
        std::lock_guard<std::mutex> lk{ m }; // lock_guardは，コンストラクターロックを実施し，デストラクターでロックを開放する
        v2.push_back(n + 100);
    }
});
// ベクトル化だと，atomic操作でデータ競合を回避する（mutexは使えない）
std::atomic<int> count(0); // タスクが終了した数
std::for_each(std::execution::par_unseq, std::begin(v1), std::end(v1), [&count](int& n) {
    n += 100;   // ほんとはもっと時間のかかる処理
    count++;
});
```

## string_view
`string_view`型はもともと「読取専用の文字列ビュー」として設計されており，関数実装側にとってもconst修飾のメリットはほぼ無い．  
文字列から`string_view`を作成するのは安価であるため，暗黙的な変換が行われる．  
`string_view`から文字列を作成するのは安価ではないため，明示的に行う必要がある．  
`std::string_view`は，Cにおける`char`と同様に扱う．  
文字列に変更を加えないのであれば、`std::string`とほぼ変わりなく使用することができる．  
`std::string_view`は文字列を実際に保持しないため，メモリー使用量を抑えられる．  
`string_view`は，生きている`char*`を参照しているだけなので，参照元の`char*`が途中でなくなってしまうと，使えなくなる．  
また，文字列の変更をすることはできない．ただし，先頭アドレスを変更したり，長さを短くしたりすることはできる． `std::string`はnull文字`\0`で終わることが保証されているが，`std::string_view`はnull文字`\0`で終わることが保証されていない．  
よって，`data()`で文字列を取り出すときには，null文字`\0`で終わっていないことに注意しなければならない．   
```cpp
#include <string_view>
void hoge0(const std::string& s) {}
void hoge1(std::string_view sv) {}
int main()
{
    // 以下は対して相違なし
    std::string str = "hoge";
    hoge0(str); // 参照渡し
    hoge1(str); // string_viewへ変換
    hoge1("hoge"); // string_viewへ変換

    std::string long_str/* 長い文字列 */;
    std::size_t pos/*開始位置*/, num/*文字数*/;
    hoge0(long_str.substr(pos, num));  // 一時オブジェクトが生成されるため非効率
    hoge1(std::string_view{ long_str }.substr(pos, num));  // 動的メモリ確保行われず効率的
}
```

## if複合文
if文の()内に変数宣言を含み，宣言された変数を利用しての判断文を記述可能になった．  
```cpp
int hoge(int n) {return 2*n;}

int fuga(int n){
    if (int a = hoge(n); a != 0) return a;
    return -1;
}
```

## テンプレートの型推論
C++17より，テンプレートの型推論が可能になった   
```cpp
std::vector<int> v;        // OK
std::vector v;             // NG
std::vector v = {1, 2, 3}; // OK（intと推論される）
std::vector v(10);         // NG（intかどうか不明）
std::vector v(10, 0);      // OK
```
